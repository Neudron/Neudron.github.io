neu
===

  Double-click  serve.bat


What is in here
---------------

  serve.bat          Starts a local web server and opens the site.
                     Close the black window to stop it.

  serve.py           The server itself. Sends no-cache headers so a
                     plain refresh always shows your latest edit.

  site\              The actual website. THIS folder is what becomes
                     the GitHub repo - not this parent folder.

  glass-proof.html   A sandbox for tuning the glass, with live sliders.
                     Reachable at http://localhost:8123/glass-proof.html
                     once serve.bat is running.


Why a server at all
-------------------

Opening index.html by double-clicking will NOT work. The page loads
three.js as an ES module through an importmap, and browsers block
modules over file:// as cross-origin. It needs to be served over
http://, which is what serve.bat does.


If the page looks stale or wrong in one browser
-----------------------------------------------

That is almost always caching. Firefox in particular will happily keep
using a stylesheet it fetched many edits ago.

  1. Make sure you are on the server started by serve.bat. If an older
     server is still running on port 8123 from a previous session, it
     will answer instead, WITHOUT the no-cache headers. Close any stray
     black console windows first.

  2. Hard refresh:  Ctrl + Shift + R    (or Ctrl + F5)

  3. Still odd? Open devtools (F12) -> Network -> tick "Disable cache",
     and leave devtools open while you work.


Tuning the glass
----------------

  1. Run serve.bat
  2. Go to  http://localhost:8123/glass-proof.html
  3. Adjust in this order - each one changes how the last one looks:
         ior  ->  thickness  ->  env intensity  ->  dispersion
  4. Click "copy settings"
  5. Paste the values into the material block in site\js\scene.js


Putting it online
-----------------

  cd "C:\Users\Neudron\Documents\neu\site"
  git init
  git add -A
  git commit -m "neu"
  git branch -M main
  git remote add origin https://github.com/neudron/neudron.github.io.git
  git push -u origin main

Then on GitHub: Settings -> Pages -> Source: Deploy from a branch
-> main -> / (root). Live at https://neudron.github.io/ in about a
minute.

Note the repo must be named exactly  neudron.github.io  for the site
to sit at the root of the domain. Any other name puts it under
/reponame/ instead.

More detail in site\README.md.
