# Dependency DAG

```text
B00 local audit and evidence
  -> B01 policies + graph/asset inventories
      -> B02 confirmed blockers, no speculative rewriting
      -> B03 world/transition/camera/save adapter
          -> B04 forest vertical slice + browser approval
              -> B05 castle
              -> B06 city + HOME
                  -> B07 inventory + crafting + FNF
                      -> B08 crack/dungeon + Mage + Polterghast
                          -> B09 cart + lift + mountain
                              -> B10 mystery + village
                                  -> B11 Draedon + finale
B05..B11 -> B12 coherent assets/audio/accessibility -> B13 release
```

Parallelizable research: room inventory, provenance checks, old-save fixture catalog, baseline screenshots, story-canon comparison. NONparallelizable within same files: engine.js camera/transition changes; rooms-a.js forest and castle changes; save.js migrations; global sprite/look passes; source tree reorganization.

Cutover invariants: legacy room traversal remains usable until both-direction forest traversal is proven; any persistent schema change has old-save fixtures; build/dev URLs retain their paths; new art must not inflate the initial portfolio page; do not increase flashing or remove keyboard/touch paths.
